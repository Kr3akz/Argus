Argus needs to read from Warframe

To show your mastery progress and your inventory, Argus reads them from the running game — the same data Warframe shows you.

  • Reading only. It never changes anything in the game, never plays for you, and never touches the game’s network traffic.
  • Your password is never involved. Argus cannot see it. It borrows the temporary session key your running game already holds — the same one the game uses itself. That key stops working when you close Warframe.
  • It goes to Warframe’s servers, nowhere else. The request goes to the same address the game itself talks to.
  • What stays on your PC. Your account ID and a copy of your inventory, so Argus need not ask again. The session key is used once and never written to disk.

Warframe has to be running, and you have to be past the login screen — in your orbiter is fine.

Game not running, or playing on console?

Enter your account ID

This works without the game running, and on any platform. Argus then shows your mastery progress — everything except the inventory, which only the running game can provide.

Where do I find it?
  1. Sign in on warframe.com
  2. Open warframe.com/api/user-data
  3. Copy the value of user_id

Since Update 38.0.8 this only works by account ID. Tools that still ask for your display name are out of date.

Resource & farming route guide

The best planets, missions and warframe setups for every resource — plus every ore and gem you can mine

Loot squad setup: Nekros (Desecrate) + Khora (Pilfering Strangledome) + speed Nova + Wisp. Nekros and Khora stack, so a squad running both roughly doubles what a solo run yields.
Boosters multiply into each other: a resource booster doubles the amount picked up, a drop-chance booster raises the odds, and a Resource Drop Chance Blessing from a relay stacks on top of both. The Steel Path adds a permanent +100% drop chance.
Always bring a beast companion with Loyal Retriever or Resourceful Retriever — both occasionally double a pickup. A Smeeta Kavat’s Charm can hand you rare resources out of thin air.
Containers are a separate table: drop-chance boosters and the Steel Path bonus do nothing for them. Only the quantity booster helps, so container farms want Xaku or Limbo, not a bigger multiplier.

Inventory access

Your public Warframe profile contains no inventory. Reading one means looking up the temporary session credentials of the running game in its process memory — read-only, never writing, and only when you press the button.
